### Actividad 1.4
la red debe cumplir con cuatro caracteristicas que se deben cumplir para enviar diferentes datos 
.Tolerancia a fallas
.Escalabilidad
.Calidad de servicio
.Seguridad

La calidad de servicio o QoS, es el conjunto de mecanismos que decide que trafico se atiende primero cuando la red no tiene capaidad suficiente para todo el tiempo 

Seguridad se refiere a proteger la red y la informacion que circula por ella contra accesos, modificaciones o interrupciones no autorizadas

.Suplantaciones de MAC/IP
.Ataques de intermediario 
.Denegación de servicio 
.Accesos no autorizados a un punto de acceso inalámbrico 

### Actividad 1.5
Una arquitectura de red es el conjunto de reglas y decisiones de diseño que definen como se organiza una red para que la comunicacion funcione: que funcion cumple cada parte.

Una red se divide dividiendola en capas independientes, donde cada capa resuelve un problema especifico sin necesitar saber como trabajar 
Modelo de referencia de siete capas fisicas, enlaces, red, transporte, sesion, presentacion y aplicacion, que describe, de forma teorica, todad las funciones que interviene en una comunicacion de red

7 CAPAS
1 fisica
2 data link
3 network
4 transport
5 session
6 presentation 
7 aplicattion 
Modelo de cuatro capas, Aplicacion, transporte, internet, acceso a red
Al bajar por las capas, cada una envuelve el dato con su propio encabezado; al llegar el adestino, el preceso se invierte y cada capa retira el encabezado que le corresponde

### UNIDAD 2
### Red de Personal(PAN)
Conecta dispositivos que pertenecen a una sola persona y estan a muy corta distancia entre si 

### red de area local(LAN)
Conecta dispositivos dentro de un espacio fisico unico
es la red que una sola organizacion controla y administra po

### Red inalambrica de area local(WLAN)
Es una LAN que usa el espactro radiolectrico en lugar de cables para conectar los dispositivos dentro del mismo espacio 
El acceso se hace a travez de uno o mas puntos de acceso a cambio de movilidad

### WIFI anal(CAN)
Conecta varias LAN de distintos edificios que pertenencen a la misma organizacion y estan proximamamente entre si 
los edificios suelen enlazar con fibra optica para soportar mayor distancia y trafico toda la red sigue bajo una sola asministracion 
### Red de area amplia(WAN)
Conecta redes que estan geograficamente distantes a veces en distintas ciudades, paises o continentes 
ya no la administracion una sola organizacion suele deender de provedores de telecomunicaciones y su costo y latdencia son mayores que una LAN

Comparacion por alcance de menor a mayor cobertura PAN (una persona) - LAN/WLAN (un edificio) - CAN (varios edificios)
